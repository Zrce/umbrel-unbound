Unbound DNS

Validating, recursive, and caching DNS resolver by NLnet Labs

Running on port 5335
DNSSEC Validates every DNS response
Recursive Queries root nameservers directly
QNAME Minimisation RFC 7816 privacy protection
No Third Party No Google, Cloudflare, or other DNS

Connect Pi-hole to Unbound

  1. Open your Pi-hole dashboard
  2. Go to Settings → DNS
  3. Remove all upstream DNS servers (uncheck Google, Cloudflare, etc.)
  4. Under Custom DNS servers, enter 127.0.0.1#5335
  5. Disable Pi-hole's DNSSEC setting (Unbound handles validation)
  6. Click Save

How It Works

Your Devices
↓
Pi-hole — port 53, blocks ads & trackers
↓
Unbound — port 5335, recursive resolver + DNSSEC
↓
Root Nameservers — authoritative answers, no middlemen
Verify it works: SSH into your Umbrel and run dig @127.0.0.1 -p 5335 example.com — you should see status: NOERROR with an answer. To test DNSSEC rejection, try dig @127.0.0.1 -p 5335 sigfail.verteiltesysteme.net — it should return SERVFAIL.
